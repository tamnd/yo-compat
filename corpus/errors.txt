# Being wrong the same way they are.
#
# Clients branch on error text. Not on an error type, because RESP does not have
# one, on the first word and sometimes on the whole string. A server that
# refuses the right commands with the wrong words breaks a client library in a
# way that looks like a bug in the library, so the wording is part of the
# protocol whether anyone likes it or not.
